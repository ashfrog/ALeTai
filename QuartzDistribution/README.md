# 「高纯石英资源分布」互动程序 设计说明

> 适用展项：阿勒泰展厅墙面液晶显示屏
> 文档版本：V1.0
> 编制日期：2026-08-02

\---

## 一、项目概述

### 1.1 项目背景

本互动展项位于阿勒泰地区展厅内的墙面液晶显示屏，搭配已完成的四张静态分布图（全球、全国、新疆、阿勒泰），通过触控交互的方式向参观者系统展示高纯石英资源在全球→全国→新疆→阿勒泰四个空间尺度上的分布情况，突出阿勒泰地区作为重要高纯石英资源富集区的战略地位。

### 1.2 设计目标

* **多尺度认知**：构建"全球 — 全国 — 新疆 — 阿勒泰"四级空间叙事，引导参观者从宏观到微观逐步聚焦。
* **可探索**：每个地图上的关键矿区均可点击，展开资源详情，让"一张图"升级为"可探索的信息库"。
* **沉浸科技感**：延续四张静态稿"暗色科技·数据可视化"基调，保持展项视觉统一。
* **零学习成本**：底部 Tab 一目了然，无文字指引即可上手。

### 1.3 运行环境

* 设备：65″–86″ 4K 触控液晶一体机（横屏）
* 分辨率：3840×2160（向下兼容 1920×1080）
* 触控：电容 10 点触控
* 启动方式：开机自启动，全屏 Kiosk 模式
* 持续运行：≥ 8 小时/天

## 二、整体架构

### 2.1 屏幕分区（统一布局）

```
┌───────────────────────────────────────────────────────────┐
│  ① 顶部标题区：主标题 + 副标题 + 关键数据（按板块出现）     │
├────────────────────────────────────┬──────────────────────┤
│                                    │                      │
│                                    │  ③ 右侧数据面板     │
│   ② 中央主地图（含可交互标注点）   │  （类型列表 / 统计   │
│                                    │   / 图例 / 占比图）  │
│                                    │                      │
├────────────────────────────────────┴──────────────────────┤
│  ④ 底部导航 Tab：全球 / 全国 / 新疆 / 阿勒泰              │
└───────────────────────────────────────────────────────────┘
```

* 顶部高度：\~10%
* 中央地图区：\~70%
* 右侧面板：\~25%（可被地图层覆盖形成全屏态）
* 底部 Tab：\~10%，固定不动

### 2.2 板块间的层级关系

* 全球板块：宏观总览，6 大洲代表矿区
* 全国板块：聚焦中国，7 类石英资源分布
* 新疆板块：聚焦新疆，6 类石英资源 + 重点矿区
* 阿勒泰板块：聚焦阿勒泰，13 个编号矿点

四个板块相互独立、由总到分，不强制按顺序浏览，但视觉引导默认从左到右（全球→阿勒泰）。

## 三、底部导航设计

### 3.1 布局

* 位置：屏幕底部固定
* 数量：4 个 Tab，等宽分布
* 每个 Tab 包含：图标 + 中文标题 + 英文副标题

  1. 🌍 全球资源分布 / GLOBAL RESOURCE DISTRIBUTION
  2. 🗺️ 全国资源分布 / NATIONAL RESOURCE DISTRIBUTION
  3. 🏔️ 新疆资源分布 / XINJIANG RESOURCE DISTRIBUTION
  4. 📍 阿勒泰资源分布 / ALTAY RESOURCE DISTRIBUTION

### 3.2 状态

|状态|视觉|
|-|-|
|默认|暗蓝底 + 半透明边框 + 图标灰色|
|Hover（鼠标悬停 / 触控按下）|边框发光 + 整体轻微上浮|
|选中（当前页）|实色填充 + 顶部光带 + 阴影 + 图标高亮|

### 3.3 切换动效

* 旧页面整体淡出（200ms）
* 新页面：背景底图先淡入，标注点由中心向四周依次扩散显示（80ms 间隔）
* 顶部标题：横向滑入 + 文字打字机效果（每字 30ms）
* 右侧面板：卡片逐张淡入（80ms 间隔）

## 四、各板块详细设计

### 4.1 板块一：全球

**标题**：高纯石英全球资源分布图
**副标题**：全球主要高纯石英矿产资源分布概览

**页面元素**：

* 顶部右上：3 项核心数据

  * 已探明储量 > 2.4 亿吨
  * 主要类型：花岗伟晶岩 / 脉石英
  * 分布特点：全球分布广泛／资源集中在特定成矿带
* 中央：世界地图（深蓝底 + 网格线 + 六大洲轮廓）
* 左下：全球主要高纯石英资源分布表（6 行）
* 右下：资源类型占比饼图 + 分布特点三图标
* 底部：图例（花岗伟晶岩型 / 脉石英型）

**6 个可交互标注点**（按地图实际位置）：

|ID|大洲|代表矿区|类型|
|-|-|-|-|
|G1|北美|Spruce Pine|花岗伟晶岩|
|G2|北欧|Nedre Øredred|花岗伟晶岩|
|G3|北亚|Kyshtym|脉石英|
|G4|东亚|阿尔泰地区|花岗伟晶岩|
|G5|南亚|Garuda|脉石英|
|G6|大洋洲|Lighthouse|脉石英|

**交互**：

* 点击标注点 → 弹出该大洲的"资源详情卡"
* 鼠标悬停 → 标注点放大 + 名称浮窗
* 列表与地图联动：悬停列表行 → 对应标注点高亮

### 4.2 板块二：全国

**标题**：全国石英资源分布图
**副标题**：QUARTZ RESOURCES DISTRIBUTION MAP OF CHINA

**页面元素**：

* 左侧：7 种石英资源类型列表（每项含：样本图、类型名、分布省份、典型矿区、储量）

  * 石英岩 / 石英砂岩 / 天然石英砂 / 脉石英 / 粉石英 / 天然水晶 / 花岗伟晶岩石英
* 中央：中国地图（按省域显示）
* 右上：各类型资源储量占比环形图（按矿种定义色板）
* 右下：数据统计 4 卡片

  * 分布省区 21 个
  * 主要矿产地 354 处
  * 保有储量 28.89 亿吨
  * 资源类型 7 大类
* 底部右下：南海诸岛缩略图

**可交互标注点**：

* 地图上的标注点按矿种着色（7 色），点位密度反映各省份各类型资源富集程度
* 点击 → 弹出"省份 × 矿种"资源详情卡
* 左侧列表项可点击 → 地图自动聚焦该类型分布的主要省份，并临时高亮其全部标注点

### 4.3 板块三：新疆

**标题**：新疆石英资源分布图
**副标题**：新疆主要石英资源类型及分布

**页面元素**：

* 左侧：6 种石英资源类型详情（与全国板块对应，但精简到新疆范围）

  * 石英岩、石英砂岩、天然石英砂、脉石英、粉石英、天然水晶、花岗伟晶岩石英
* 中央：新疆轮廓地图（带地形纹理 + 主要山脉标注）
* 右上：新疆在中华人民共和国的位置缩略图
* 右下：阿尔泰地区花岗伟晶岩石英重点说明卡
* 底部：比例尺（0–500 km）

**可交互标注点**：

* 各类型矿点按图例着色
* 重点矿区：阿尔泰地区、托克逊、和田、阿克陶、柯坪县、托里县、奇台县、鄯善县、若羌县等
* 点击 → 弹出该矿点详情（矿区名、类型、储量、位置）
* 重点标注（阿尔泰地区花岗伟晶岩石英）→ 提供"跳转阿勒泰板块"的快捷按钮

### 4.4 板块四：阿勒泰

**标题**：阿勒泰地区矿产资源分布图
**副标题**：LOCAL RESOURCES DISTRIBUTION

**页面元素**：

* 左侧：图例 + 矿石类型 + 矿点统计

  * 县界 / 国界 / 乡镇界限
  * 伟晶岩型高纯石英（红色三角）13 处
  * 脉石英型高纯石英（黄色方块）2 处
* 中央：阿勒泰地区地图（含 6 县 1 市：哈巴河县、布尔津县、吉木乃县、福海县、富蕴县、青河县、北屯市、阿拉泰市等）
* 顶部装饰边 + 罗盘 + 比例尺
* 右下：当前选中矿点的详细数据卡（默认显示汇总）

**13 个编号矿点**（红色三角 11 处 + 黄色方块 2 处）：

* 编号 1–13，点击任一矿点
* 右侧数据卡切换为该矿点详情：编号、名称、坐标、类型、储量、品位、交通条件、备注
* 地图相应标注点高亮 + 周边 200km 范围做柔光圈提示

**额外功能**：

* 顶部"全屏查看"按钮：可隐藏右侧数据卡，让地图占满整个画面
* 底部"重置视图"按钮：地图归位中心

## 五、标注点交互设计

### 5.1 标注点视觉规范

* **默认态**：实心彩色光点（直径 12–16px）+ 微弱呼吸光圈（2s 循环）
* **Hover / 按下**：光圈扩散 + 放大 1.2 倍 + 名称浮窗
* **选中态**：持续高亮（金色描边）+ 锚定弹窗 + 周边柔光
* **常驻光晕**：与地图已有"会发光"的视觉风格一致

### 5.2 详情弹窗

* 位置：默认从标注点右侧弹出，靠近屏幕边缘时自动翻转（避免溢出）
* 样式：暗色玻璃质感卡片 + 顶部彩色色带（对应类型）+ 关闭按钮 ✕
* 内容结构：

  1. 矿区名称（中英文 + 编号）
  2. 资源类型（彩色徽标）
  3. 关键数据：储量、品位、规模
  4. 简短描述（2–3 行）
  5. 可选：实景图、所属公司、联系方式
  6. 操作按钮：关闭 / 跳转相关板块 / 在地图上居中显示

### 5.3 列表与地图联动

* 左侧/右侧列表项与地图标注点双向高亮
* 鼠标悬停列表项 → 地图对应点位发光 + 名称浮窗
* 鼠标悬停地图点 → 列表项同步高亮 + 滚动到可视范围

## 六、动效设计

### 6.1 全局动效

* 页面切换：整体淡入淡出（200ms）
* 地图轮廓加载：路径由外向内描边（1.2s ease-out）
* 标注点出现：按 ID 顺序从中心向外扩散（80ms 间隔）
* 数据卡片：依次淡入（80ms 间隔，最多 6 张）

### 6.2 微交互

* 按钮按下：scale(0.95) + 阴影变化（100ms）
* 标注点：呼吸光圈（2s 循环，放大 + 透明度衰减）
* 数字加载：滚动计数（1s 缓动）
* 列表项 Hover：背景填充 + 左侧色条显现

### 6.3 特殊转场（板块切换）

* 旧板块：标注点向中心聚拢 → 淡出
* 新板块：地图描边 → 标注点从中心扩散 → 面板依次淡入
* 顶部标题：横向滑入 + 文字打字机效果

### 6.4 待机模式

* 60 秒无操作 → 自动循环播放四板块（每板块 30s）
* 自动播放期间标注点做"扫描"动效，提示可交互
* 任意触控 / 鼠标操作 → 立即停止自动播放

## 七、技术实现建议

### 7.1 技术栈

* **前端框架**：Vue 3（推荐）或 React
* **构建工具**：Vite
* **地图绘制**：SVG 自绘（数据量小、缩放灵活）或 D3.js / Leaflet
* **动效**：GSAP / anime.js / CSS Animation
* **部署**：本地静态文件 + Nginx 或简单 HTTP 服务，浏览器 Kiosk 全屏

### 7.2 数据结构（JSON）

```json
{
  "points": \\\[
    {
      "id": "G1",
      "section": "global",
      "name": "Spruce Pine",
      "name\\\_cn": "北美洲",
      "type": "granite-pegmatite",
      "type\\\_cn": "花岗伟晶岩",
      "lon": -82.0,
      "lat": 35.9,
      "data": {
        "reserves": "约 1,000 万吨",
        "grade": "SiO₂ > 99.99%",
        "description": "全球最大高纯石英产区..."
      }
    }
  ]
}
```

### 7.3 性能指标

* 首次加载：≤ 3s
* 板块切换响应：≤ 300ms
* 帧率：≥ 60fps
* 内存占用：≤ 1GB
* CPU 占用：≤ 30%（持续运行）

### 7.4 离线与容错

* 所有地图、标注点数据本地化
* 异常时降级为静态展示（不卡死）
* 启动失败自动重启浏览器

### 7.5 安全与限制

* 禁用右键、F12、文本选择
* 启动时全屏 + 隐藏鼠标光标（可选）
* 仅运行本应用，禁止切换其他程序

  * 天然石英砂：#ffd166
  * 脉石英：#2da8ff
